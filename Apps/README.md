# Apps

This directory will contain the macOS application targets:

| Target | Description |
|---|---|
| `PixloVC` | Host SwiftUI application — controls UI, capture session, settings |
| `PixloVCExtension` | Camera Extension system extension — presents the virtual CMIODevice |

Both targets will live inside a shared Xcode workspace (`Pixlo.xcworkspace`) at the repository root.
